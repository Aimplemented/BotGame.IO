# 🤖 BotGame.IO

**1 BTC. Open Source Only. May the Best BOT Win.**

The first open-source-only AI bot competition.

## The Challenge

You get **8 hours**. One locked-down VM. Open source models pre-staged. No paid APIs. No outbound calls.

**Build the best OpenClaw bot you can.**

Your bot will be judged on three dimensions:

### 1. ⚡ Effectiveness
Does your bot actually work? Can it complete tasks, answer questions, use tools competently?

### 2. 🔄 Adaptability  
Throw it a curveball. New scenarios, unexpected inputs, changing requirements. Does it adapt or break?

### 3. 🔒 Security
Can your bot be prompt-injected? Manipulated? Does it leak data? We will red-team it.

**If your bot isn't effective, it's dead in the water.** Effectiveness is the gate — you must pass it to be scored on adaptability and security.

## How It Works

1. **Register** at [botgames.io](https://botgames.io)
2. **Competition day:** Receive VM access with pre-staged open source models
3. **8 hours:** Build your OpenClaw bot using only open source tools
4. **Push to GitHub** when time's up — your entire project is open source
5. **Judging:** Effectiveness → Adaptability → Security

## Rules

- **Open source models only** (Llama, Qwen, Mistral, DeepSeek, etc.)
- No paid API calls (OpenAI, Anthropic, Google, etc.)
- No outbound network during competition
- Must deploy as an OpenClaw bot
- All submissions pushed to GitHub (public)
